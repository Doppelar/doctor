# doctor

血液内科医への製薬会社の支払い（講師謝金・原稿執筆料・コンサルティング料など）を、医師ごとにまとめる自分用のアプリです。

- 医師の一覧は、講演会カレンダーのデータベース（`events` テーブル）にある演者・座長から作ります（読み取りのみ）。
- 支払いは、各社が「企業活動と医療機関等の関係の透明性ガイドライン」に沿って公開しているデータを、手で登録するか貼り付けて登録します（`payments` テーブル）。
- 画面と API はパスワードで保護し、検索エンジンにも載せません。

このリポジトリにはコードだけを置き、支払いのデータやパスワードは含みません。

## 環境変数

| 名前 | 内容 |
| --- | --- |
| `DATABASE_URL` | Neon（PostgreSQL）の接続文字列 |
| `PAYMENTS_PASSWORD` | 画面を開くためのパスワード |

## 開発

```bash
npm install
npm test        # 純粋関数のテスト（vitest）
npm run build   # 型チェック + ビルド
```

API は `api/` 配下の Vercel Functions です。ローカルで API ごと動かすには `vercel dev` を使います。

## 貼り付け登録の列

`医師名, 所属, 会社, 年度, 区分, 件数, 金額, 出典URL, 備考`（1行目に見出しがあればその順番で読みます）
